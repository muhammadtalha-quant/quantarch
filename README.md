# My NixOS Configuration
A completely modular, declarative, reproducible system written purely in Nix expression language.

---
## 🛠️ The Stack

This repository houses my entire system architecture, split cleanly into two distinct layers:

* **❄️ Nix Flakes:** Manages the core operating system, hardware configurations, system-level daemons, and kernel parameters.
* **🏠 Home Manager:** Handles my user environment, managing everything from my shell aliases and git configs to full application setups.
